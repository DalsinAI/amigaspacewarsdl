# Spacewar for GFOS

The AmiCradle Team's port of Spacewar 0.3 (spacewar-sdl), a two-player
duel in space on one keyboard, to GFOS (AmigaOS 3.2 with GFOpenUp),
68040/68060 + FPU, on GFOpenUp's SDL 2. Upstream is fetched at build
time and never kept here. See AMIGA_PORT.md.

Designed, tested and delivered by The AmiCradle Team.
